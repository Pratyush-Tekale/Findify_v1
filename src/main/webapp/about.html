About This Build

Findify is a College Lost & Found Management System developed as a BCA Final Year Project. It provides a simple platform where students can report lost items, browse found items, verify ownership, and claim their belongings quickly and securely.

🎯 Project Objective

The main objective of Findify is to reduce the time and effort required to recover lost belongings by providing a centralized online platform for reporting and tracking lost and found items.

✨ Key Features

  • ✔ User Registration & Login
  • ✔ Report Lost Item
  • ✔ Browse Found Items
  • ✔ Verify Ownership Before Claiming
  • ✔ Secure Claim Request
  • ✔ Contact Admin
  • ✔ Rules & FAQ
